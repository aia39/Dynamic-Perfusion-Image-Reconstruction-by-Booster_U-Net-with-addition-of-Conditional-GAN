## Run
1. First install a environment containing pytorch-gpu
2. Run the 'run.py' function for execute the inference code and get output images and results
3. To train the network, run the code 'train_network.py'
4. Trained weight will be saved in the folder trainedNetwork.

## Data
1. Dataset will be organized in a parent folder containing folders named 'training', 'valid', 'testing' (all are mat files)
2. The dataset which was tested can not be disclosed, so any similar dynamic data can be used to validate.
